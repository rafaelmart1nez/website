Step 1. Sign in first

Nothing else runs until login succeeds. A separate Microsoft sign in window opens, you enter the admin account, password, and MFA there, and EntraFlow discovers the tenant from that sign in. No tenant ID is ever typed.

Step 3. Pick tenant items by search

Every list below comes from the signed in tenant. Pick by name, never by ID. If a blueprint search finds nothing, the full list is shown instead, and a missed search never stops the run.

Step 4. Review before it runs

This is exactly what the pipeline will do. Stages with nothing selected are skipped cleanly, with the reason recorded in the audit trail.

Step 5. Run the pipeline

Five stages run in order. Stage independence means one stage can be skipped or fail without stopping the rest, and every call lands in the audit trail below.
